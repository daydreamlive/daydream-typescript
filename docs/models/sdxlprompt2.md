# SDXLPrompt2

Text prompt describing the desired image. Can be a single string or weighted list of (prompt, weight) tuples.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `models.SDXLPrompt1[][]`

```typescript
const value: models.SDXLPrompt1[][] = [
  [],
  [
    7515.28,
  ],
  [
    9998.02,
  ],
];
```
