# Sdxl3Seed2

Random seed for generation. Can be a single integer or weighted list of (seed, weight) tuples.


## Supported Types

### `number`

```typescript
const value: number = 128403;
```

### `models.Sdxl3Seed1[][]`

```typescript
const value: models.Sdxl3Seed1[][] = [
  [
    256.3,
  ],
  [
    7617.21,
  ],
  [],
];
```
